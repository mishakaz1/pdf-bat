## PDF-Bat 0.1.0 — first version

**Read mode:** several PDFs side by side, duplicate a pane to read two places of one book, last page remembered, contents sidebar (PDF bookmarks or auto-detected headings), highlight / underline / strike, pen, marker, eraser, sticky notes, bookmarks, thumbnails, find, links with back/forward, snapshot to clipboard, reading ruler, dark pages, dark/light theme. Annotations are saved inside the PDF.

**Edit mode:** add text, images, shapes, whiteout; edit existing text; signature; fill forms; reorder / rotate / delete / insert / extract / crop pages; Save and Save As.

LaTeX arrives in 0.2.

### Install
- **Windows:** `PDF-Bat-Setup-0.1.0.exe`. SmartScreen may warn (not code-signed yet): *More info → Run anyway*.
- **macOS:** `arm64` .dmg for Apple Silicon (M1–M4), `x64` for Intel. First launch: right-click PDF-Bat → *Open*. If macOS says it is damaged: `xattr -cr /Applications/PDF-Bat.app` in Terminal.
